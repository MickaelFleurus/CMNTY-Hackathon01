# CMNTY Hackathon 01 — Vampire Survivors

Vampire-survivors-style game built with [KAPLAY](https://kaplayjs.com/) + Vite.

## Getting started

```sh
npm install
npm run dev
```

Open the printed localhost URL in your browser.

## Workflow

- `main` is protected-ish: keep it stable.
- Each teammate works on their own branch, e.g. `git switch -c yourname/feature`.
- Commit early, push often, open PRs against `main`.

## Structure

- `index.html` — Vite entry point
- `src/main.js` — game entry (KAPLAY scene setup)
